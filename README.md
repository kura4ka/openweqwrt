# Xiaomi BE7000 QWRT sysupgrade

Этот репозиторий собирает образ обновления (`sysupgrade.bin`) для Xiaomi BE7000
с установленной QWRT и односекционной разметкой: UBI находится в MTD `rootfs`,
а внутри него используются тома `kernel`, `rootfs` и `rootfs_data`. Отдельный
MTD `overlay` образ не подключает и не изменяет.

Сборка основана на [порту BE7000](https://github.com/kravasuper/openwrt) с
закреплённым исходным коммитом `790d036a`. Workflow собирает только sysupgrade,
не выпускает factory-образ, пакетный feed или GitHub Release и прикладывает
sysupgrade, manifest и SHA-256 к запуску GitHub Actions. Артефакт хранится 14
дней. Сборка запускается при обновлении ветки `main` или вручную во вкладке
**Actions → Build QWRT sysupgrade**.

Для обновления скачайте `xiaomi-be7000-qwrt-squashfs-sysupgrade.bin` из
артефактов успешной сборки и загрузите его через страницу обновления QWRT.
Оставьте включённым сохранение конфигурации и заранее сохраните резервную копию.
Образ заменяет содержимое MTD `rootfs` и пересоздаёт `rootfs_data`; пакеты и
данные приложений, отсутствующие в архиве конфигурации, могут потеряться.

Этот файл предназначен для указанной разметки QWRT. Не используйте его для
установки со штатной двухслотовой разметкой и не используйте factory-образ.
Проверка SHA-256 подтверждает целостность загрузки, но не гарантирует загрузку
на устройстве с другой разметкой.
