# Сборка QWRT

[English](building.en.md)

Сборку запускает workflow `.github/workflows/build.yml` на GitHub Actions — при
push в `main` или вручную через **Actions → Build QWRT sysupgrade → Run workflow**.
Результат — sysupgrade для односекционной разметки QWRT, manifest и SHA-256 в
артефакте Actions. Workflow не собирает factory-образ и не публикует feeds или
GitHub Releases.

Этот репозиторий содержит интеграционный слой проекта
[timofey-maykov/be7000-openwrt](https://github.com/timofey-maykov/be7000-openwrt):
файлы релиза 1.3.1 (`8b7c2fb3372a548fd3562ee4f77d2ce9691ba1f3`) —
`config.buildinfo`, закреплённые feeds, патчи, overlay, `awg-feed` и тему LuCI.
Само дерево OpenWrt workflow клонирует из порта
[kravasuper/openwrt](https://github.com/kravasuper/openwrt), ветка
`xiaomi_be7000`, коммит `790d036a178c0f695c2f60d490d194091b35e595`, как
предписано исходным проектом. Обе версии также записаны в `source.buildinfo`.

Профиль `profiles/qwrt` задаёт DTS, UBI volume и обработчик sysupgrade для
установленной разметки QWRT. Upstream-патчи `001`, `003` и `005` пропускаются:
первый включает bootargs и RF-настройки для иной разметки, третий выбирает слот,
а исправление регулятора `005` уже включено в QWRT DTS. Вместо них профиль
использует собственные DTS, UBI-volume и sysupgrade патчи. Они пишут только в
MTD `rootfs`, не выбирают `rootfs_1`, не меняют флаги загрузчика и не подключают
отдельный MTD `overlay`.

В версии проекта 1.3.1 добавлен режим двух радио 5 ГГц. Сборка включает патчи
ath12k `308`–`310`, DTS-патчи `006`–`008`, образ платы и службы переключения.
Патч `007` применяется после QWRT DTS-патча, который создаёт RF GPIO hogs,
заменяемые на управляемое pinctrl-состояние. DTS резервирует 12 МиБ под dual-MAC
прошивку; обычный режим одного радио остаётся режимом по умолчанию. Патч `009`
сохраняет привычный префикс `openwrt-` в имени образа.

Workflow сохраняет проверку подписи пакетов, но отключает updater из образа и
не публикует feed: сборка предназначена для QWRT-разметки, а не для upstream
двухслотовой системы обновления.

Перед сборкой workflow исправляет hunk-count в патче `307`, который уже входит
в закреплённый порт Krava (`790d036a`): заголовок объявляет 7/6 строк, хотя в
патче 6/5. Это нужно, чтобы пакет mac80211 мог применить исходную очередь
патчей перед новыми `308`–`310`.

После успешного запуска скачайте `xiaomi-be7000-qwrt-squashfs-sysupgrade.bin` из
артефакта и проверьте SHA-256 по `sha256sums.txt`. Используйте образ только через
штатное обновление QWRT на устройстве с этой разметкой.
